# GoreeCloud Reader — Glaze UI Adoption

## Target

Reader currently targets **Stable Glaze UI 1.3.0** as declared by the current GoreeCloud application/platform precedent.

## Foundation adoption

The web and Android shells apply the following direction:

- strong content hierarchy;
- artwork-first media cards with readable metadata;
- layered/translucent surfaces where appropriate;
- responsive layouts;
- generous touch targets;
- visible keyboard focus on web;
- reduced-motion support on web;
- high-contrast-friendly tokens;
- clear selected/filter state;
- explicit unavailable-state messaging.

## Acceptance status

**Not accepted yet.** Repository-local visuals are not proof of Glaze UI conformance. Reader must complete the applicable consumer/adoption and accessibility acceptance process against the authoritative Glaze UI repository before `goreecloud.platform.yaml` may claim a conformant state.

## Reader-specific future components

Planned design work includes cover grids, shelves, title/series detail pages, distraction-free reader chrome, manga spread controls, webtoon navigation, EPUB typography controls, PDF navigation, audiobook Now Playing, downloads, annotations, and responsive tablet/large-screen layouts.

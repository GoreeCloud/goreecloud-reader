# GoreeCloud Reader — Benefits

## Product value

GoreeCloud Reader is designed to consolidate personal books, manga, comics, and audiobooks into one self-hosted application without reducing those media types to generic file viewing.

Planned user benefits include:

- one organized private library across visual, textual, and audio publications;
- specialized reading and listening experiences for each medium;
- preservation of original source files;
- portable progress, annotations, collections, and metadata;
- cross-device continuity without making a third-party hosted service authoritative;
- accessible interfaces designed around GoreeCloud Glaze UI;
- user-controlled optional integrations rather than mandatory content-provider dependencies.

## Current foundation benefit

The current `0.0.1-foundation` provides a safe development baseline: web and Android shells can exercise library interaction patterns with synthetic data while real personal-media processing remains fail-closed pending required Platform-System integration.

This separation allows interface and domain development to progress without falsely implying privacy, security, synchronization, or media-processing capabilities that have not yet been accepted.
